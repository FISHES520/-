# 开发与部署说明

## 环境

- Java 21、Maven 3.9+
- Node.js 20+、npm
- MySQL 8.0

## 配置

复制 `.env.example` 为 `.env`，设置 MySQL 连接、至少 32 字节的 JWT 密钥。AI 配置可留空；留空时智能伴学明确提示服务未配置。生产环境应通过部署平台注入变量，不提交密钥。

创建数据库 `history_platform` 后启动后端；Flyway 会自动执行迁移。前端通过 `VITE_API_BASE_URL` 配置 API 地址，默认使用 Vite `/api` 代理。

## 首次账户

首次部署使用注册页面创建账户。新账户默认学生角色；教师和管理员角色需要由已有管理员授予。演示数据明确标为“演示”。

## 验收边界

本仓库阶段文档分别记录静态实现情况与待执行验收。需要在目标环境执行构建、迁移和浏览器联调后，才能确认运行状态；源代码存在不代表这些检查已经通过。
