
**《现代历史学》国家级一流本科课程智慧教学平台**

平台面向高校历史学专业课程，融合传统课程资源管理、知识图谱、互动教学、学习过程分析与 AI 智能助学功能。

项目不是普通的后台管理系统，也不是简单的课程展示网页，而是一个兼具以下特征的综合平台：

- 国家级一流本科课程的学术展示平台
- 面向学生的在线自主学习平台
- 面向教师的智慧教学与课程管理平台
- 基于知识图谱的历史知识组织与探索平台
- AI 驱动的历史学智能学习辅助平台

所有页面使用真实的前后端交互机制，不能仅实现静态展示或没有功能的按钮。

## 二、技术架构

采用前后端分离架构。

### 1. 前端

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- Element Plus
- Tailwind CSS
- Axios
- ECharts
- Apache ECharts Graph 或 AntV G6（知识图谱）
- Markdown 渲染与富文本编辑器

使用 Composition API 和 `<script setup>`。

前端要求组件化、响应式、支持桌面端和平板端，移动端完成核心功能适配。

### 2. 后端

- Java 21
- Spring Boot 3
- Spring Security
- JWT 身份认证
- Spring Data JPA 或 MyBatis-Plus，统一选择一种主要持久化方案
- Hibernate Validator
- Springdoc OpenAPI
- Maven

后端按照 Controller、Service、Repository/Mapper、Entity、DTO、VO 等层次组织。

统一接口响应结构、错误码、全局异常处理、分页机制和参数校验。

### 3. 数据与存储

- MySQL 8.0
- Redis（可选，用于缓存及会话优化）
- 本地文件存储（开发环境）
- 可扩展的对象存储接口（生产环境可对接 OBS 或 MinIO）
- 数据库迁移工具 Flyway

所有核心业务数据均持久化到 MySQL。不得用前端 localStorage 充当业务数据库。

### 4. AI 能力

后端通过独立 AI Service 封装第三方大模型接口，使用兼容 OpenAI 风格的 API 配置。

支持：

- 历史知识智能问答
- 历史事件解释
- 历史概念对比
- 根据课程资源生成练习题
- 学习薄弱点分析
- 历史知识关联推荐

优先实现有来源引用的课程资料检索增强生成（RAG）。在无模型密钥时，提供明确的功能配置提示，而不是伪造 AI 回答。

AI 密钥必须存储于后端环境变量，禁止暴露在浏览器中。

## 三、整体视觉设计

### 1. 设计理念

整体采用：

**现代数字人文 + 高校学术气质 + 历史文化美学 + 智慧教学科技感**

首页应具有国家一流课程门户网站的品质，避免常见的通用 Element Plus 后台模板式设计。

参考高校精品课程网站、数字博物馆、历史档案馆与高品质教育 SaaS 平台的设计语言。

### 2. 色彩方案

主要配色：

- 深海军蓝：#183153
- 学术藏蓝：#203D62
- 古典金色：#C6A66B
- 宣纸米白：#F7F4ED
- 历史棕色：#8B7155
- 正文深灰：#27313F

页面整体以米白色或浅暖灰色背景为主，导航采用深蓝色，金色用于标题强调和关键细节。

不要大量使用高饱和度渐变、霓虹色或突兀的玻璃拟态效果。

### 3. 页面设计细节

- 顶部固定式全局导航
- 大幅历史主题 Hero Banner
- 精致的课程介绍区
- 时间轴形式的历史内容展示
- 卡片式课程章节与学习资源
- 可交互知识关系图谱
- 数据可视化学习分析页面
- 大量留白、清晰的信息层级
- 微交互及平滑过渡动画
- 统一的空状态、加载状态与错误状态

可使用符合授权要求的历史档案、手稿、地图、人物肖像和古籍图片。图片需要标明来源，不得伪造历史文献。

中文字体应体现正式、优雅、易读的高校学术风格。

## 四、用户角色和权限

实现三种主要角色：

### 游客

- 查看首页
- 查看公开课程介绍
- 浏览教学团队
- 查看公开公告
- 预览部分开放课程资源

### 学生

- 学习课程章节
- 查看教学日历
- 学习视频、文档和资源
- 使用问题图谱
- 完成闯关答题
- 进行错题回补
- 查看学习进度
- 查看个人雷达图与学习成果
- 参与课堂投票、词云和讨论
- 使用 AI 智能学伴

### 教师与管理员

教师可以管理自己负责的课程内容、题目、学生学习情况及课堂活动。

管理员可以管理用户、角色、权限和全站设置。

后端必须执行基于角色及资源归属的权限校验，不能只通过隐藏前端按钮实现访问控制。

## 五、网站栏目结构

严格按照以下栏目实现一级导航与二级页面。

### 1. 首页

面向所有用户。

包含：

- 课程封面与宣传 Banner
- 课程简介
- 课程宣传片
- 课程亮点数据
- 核心课程特色
- 最新公告
- 课程章节快捷入口
- 教学团队展示
- 历史事件精选时间轴
- AI 智慧教学特色介绍

首页需要具备完整的课程门户体验。

### 2. 课程导览

二级栏目：

1. 课程介绍
2. 教学大纲
3. 教学日历
4. 教学团队

课程介绍展示教学目标、课程定位、课程特色与考核方式。

教学大纲支持章节目录、学习目标和内容说明。

教学日历按周次展示教学安排、任务与相关资源。

教学团队提供教师照片、研究方向、学术成果与教师介绍。

### 3. 问题图谱

二级栏目：

1. 主线地图
2. 关卡地图
3. 进度总览

**主线地图：**

以历史时代与历史问题为主线构建互动知识图谱。

节点可包含：

- 历史时期
- 历史事件
- 历史人物
- 历史概念
- 历史文献
- 史学研究方法
- 核心问题

节点之间具有先后、因果、影响、关联、争议等关系。

点击节点可以打开知识详情、关联课程章节和学习资源。

**关卡地图：**

以问题链组织关卡学习。

每个关卡具有题目、前置知识、完成条件、积分与反馈机制。

**进度总览：**

展示学生的节点探索率、关卡通过率、知识点掌握程度和学习进度。

### 4. 学习中心

二级栏目：

1. 闯关答题
2. 错点回补
3. 我的雷达
4. 我的成果

**闯关答题：**

支持单选、多选、判断、填空、简答等题型。

题目与知识点绑定，支持逐关挑战、答题解析、成绩记录。

主观题支持教师批阅。AI 可提供辅助反馈，但不得直接替代教师的正式评分决定。

**错点回补：**

根据学生错题自动整理薄弱知识点，推荐相关课程资源及针对性练习。

**我的雷达：**

展示多维度学习能力，包括：

- 历史事实掌握
- 时间脉络分析
- 史料解读
- 历史解释
- 比较分析
- 史学方法运用

以上维度的数据必须来自可解释的测评规则。

**我的成果：**

包括答题记录、学习时长、课程完成度、个人成就与阶段成绩。

### 5. 资源中心

二级栏目：

1. 八类资源检索
2. 按节点调取资源
3. 按错点调取资源

资源分为八种类型：

1. 教学视频
2. 教学课件
3. 历史文献
4. 历史地图
5. 历史图片
6. 学术论文
7. 经典著作
8. 练习题库

支持关键词搜索、类型筛选、章节筛选、标签筛选、预览和下载权限控制。

资源与知识图谱节点、题目、课程章节建立关联。

### 6. 课堂互动

二级栏目：

1. 词云
2. 投票
3. 抢答
4. 分组
5. 热力图

**词云：** 学生提交历史议题关键词，并生成动态词云。

**投票：** 教师发布选择性议题，学生实时投票，展示实时统计。

**抢答：** 教师创建限时抢答活动，学生参与抢答和结果提交。

**分组：** 教师创建学习小组，发布历史问题研讨任务。

**热力图：** 可视化学生在章节、题目或知识点上的参与度与掌握情况。

课堂互动应使用 WebSocket 或可靠的短轮询机制，支持真实的多用户参与。

### 7. 智能伴学

二级栏目：

1. 识势应变君
2. 史势评议官（二期规划）

**识势应变君：**

作为平台 AI 历史学习助手，支持：

- 自然语言历史问答
- 历史事件背景分析
- 时间线生成
- 历史人物对比
- 历史事件因果关系讲解
- 史料辅助解读
- 课程知识点推荐
- 根据课程材料生成复习题

回答应尽量标明知识依据、课程资源引用与不确定性。

**史势评议官：**

规划为历史议题讨论与多观点分析功能。

支持围绕历史解释展开讨论、分析不同史学观点，并提供证据评价建议。

该模块作为二期功能，第一期预留导航入口、后端接口边界和页面占位即可，明确标注“规划中”。

### 8. 管理后台

二级栏目：

1. 问题管理
2. 题目管理
3. 资源管理
4. 雷达查看
5. 终评管理
6. 系统设置

问题管理支持图谱节点与问题链配置。

题目管理支持增删改查、批量导入、题库分类、答案及解析管理。

资源管理支持上传、分类、版本更新和知识节点关联。

雷达查看展示班级及学生个体的学习能力分布，并提供权限控制。

终评管理支持成绩构成配置、过程性评价、人工复核与成绩导出。

系统设置支持用户、角色、权限、公告与课程基础信息管理。

## 六、现代历史学课程内容设计

为平台预置结构化的演示课程内容。

采用以历史研究方法与近现代世界历史问题为核心的课程组织方式。

建议演示章节：

1. 历史学导论与现代史学方法
2. 史料、史实与历史解释
3. 文艺复兴与思想变迁
4. 宗教改革与近代欧洲社会
5. 启蒙运动与近代政治思想
6. 工业革命与社会经济转型
7. 民族国家与现代国家体系
8. 帝国主义、殖民扩张与全球联系
9. 两次世界大战与国际秩序重构
10. 冷战、去殖民化与全球化
11. 当代史学的新议题与研究方法

以上为演示课程目录，必须支持教师后续修改，不能将其写死在组件中。

课程内容应体现史学问题意识、史料分析能力与多视角历史解释。

不能把虚构的演示文本当成真实学术成果；示例数据应有明确标识。

## 九、关键交互要求

所有核心按钮必须具有实际行为。

例如：

- 点击课程章节进入对应详情页
- 点击图谱节点加载其详情和相关资源
- 点击“开始挑战”从后端读取题目
- 提交答案后保存作答记录
- 完成关卡后更新进度
- 错题自动进入错点回补模块
- 点击学习雷达查看数据库中的测评结果
- 教师发布投票后学生可以参与
- 教师上传资源后学生可以按权限查看
- AI 聊天记录保存在数据库中
- 管理后台修改课程内容后前台同步显示

对于未实现的扩展功能，必须清晰展示规划状态，而不是使用假数据伪装为完整功能。

## 十、页面原型与开发顺序

优先实现以下完整页面路径：

登录页 → 首页 → 问题图谱页 → 关卡详情页（问题与关联资源） → 答题与判分页 → 我的雷达页 → 资源中心页 → 管理后台。

每个页面只突出一项主要操作，避免页面堆积大量不相关信息。

分阶段进行开发：

**第一阶段：项目基础**

完成前后端工程、数据库、登录认证、权限、公共布局、导航系统。

**第二阶段：课程门户**

完成首页、课程介绍、教学大纲、教学日历、教学团队和公告模块。

**第三阶段：智慧学习核心**

完成知识图谱、闯关答题、错题回补、学习进度与能力雷达图。

**第四阶段：资源与后台**

完成八类资源管理、教师后台、题目管理及过程性评价。

**第五阶段：课堂互动和智能伴学**

完成词云、投票、抢答、分组、热力图及 AI 历史智能问答。

**第六阶段：测试与交付**

完成核心业务测试、接口联调、数据库初始化、权限检查、响应式适配和部署文档。
